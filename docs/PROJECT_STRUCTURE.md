# Структурный рефакторинг Marvin.io

## Цель

Разложить проект по нормальным папкам без переписывания логики и без изменения пользовательского поведения.

## Что куда вынесено

| Было | Стало | Зачем |
|---|---|---|
| `style.css` | `assets/css/style.css` | Стили отдельно от логики |
| `logo.svg` | `assets/img/logo.svg` | Все изображения в одном месте |
| `image/` | `assets/img/` | Единая папка ассетов |
| `script.js` | `src/app/app.js` | Основная логика приложения отдельно |
| `diagnostics.js` | `src/app/diagnostics.js` | Диагностика рядом с приложением |
| `firebase-*.js` | `src/auth/` | Авторизация и синхронизация отдельно |
| `*_data.js`, `conspects.js` | `src/data/` | Учебный контент отдельно от логики |
| `physics_all_solutions.md` | `docs/physics_all_solutions.md` | Справочные материалы отдельно |
| `AGENTS.md` | `docs/AGENTS.md` | Техническая история отдельно |

## Что намеренно не трогалось

- Логика прогресса.
- Формат localStorage.
- Firebase-логика.
- Содержимое конспектов и задач.
- Рендеринг вкладок.
- HTML-структура страницы, кроме путей к файлам.

## Следующий безопасный этап

1. Вынести из `src/app/app.js` чистые функции хранения прогресса в отдельный файл.
2. Вынести рендеры вкладок по разделам.
3. Добавить маленький слой `api/storage.js`, чтобы потом заменить localStorage/Firebase на backend без переписывания всего UI.
4. Перевести учебный контент из JS-строк в Markdown/JSON.
