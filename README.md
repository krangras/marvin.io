# 📚 Marvin.io — АГиТДУ

> Интеллектуальная система интервальных повторений для подготовки к экзамену по АГиТДУ (Алгебра, геометрия и теория дифференциальных уравнений) + контрольная работа по ЛДУ-II.

## 🔥 Возможности

- **Интервальные повторения** по билетам (алгоритм Лейтнера: 1 → 3 → 7 → 14 → 30 дней)
- **Полные дословные конспекты** с доказательствами и LaTeX-формулами
- **Детальная статистика** прогресса: очки, ранги, количество повторений каждого билета
- **Умный таймер** до экзамена (с точностью до 3 знаков)
- **Персональный темп** – показывает, сколько дней в среднем есть на один новый билет
- **Сохранение и загрузка** прогресса (JSON-файлы) – не потеряешь свои успехи
- **История повторений** каждого билета – наглядный календарь
- **Вкладки** – отдельно экзаменационные билеты и контрольная работа
- **Адаптивный дизайн** – удобно на любом устройстве
- **KaTeX** – красивые формулы как в учебнике

## 🚀 Быстрый старт

### Локальный запуск

1. Скачай все файлы проекта:
   ```
   index.html
   style.css
   script.js
   conspects.js
   ```
2. Помести их в одну папку.
3. Открой `index.html` в любом современном браузере (Chrome, Firefox, Edge, Safari).

> Никаких серверов, баз данных и установок не требуется – всё работает локально в вашем браузере.

### Первое использование

- На вкладке **«Экзамен (билеты)»** – список из 19 билетов.
- Нажми **«Изучить»** на первом билете – он перейдёт на шаг 1, и следующее повторение будет назначено через 1 день.
- После каждого успешного повторения интервал увеличивается: 1 → 3 → 7 → 14 → 30 дней.
- Если забыл – нажми **«↩️ Откатить»** (шаг уменьшится, дата повтора сдвинется).
- Кнопка **📜** показывает историю всех повторений билета (даты).
- Прогресс автоматически сохраняется в браузере (`localStorage`).
- Можно сохранить прогресс в файл (💾) и загрузить позже (📂) – удобно для переноса между устройствами.

## 📖 Структура конспектов

Конспекты хранятся в файле `conspects.js` и содержат **дословные** формулировки теорем, определений и доказательств из лекций. Все математические выражения оформлены в **LaTeX** и отображаются через KaTeX.

Пример оформления:

```javascript
const CONSPECTS = {
    0: `<div>... конспект билета 1 ...</div>`,
    1: `<div>... конспект билета 2 ...</div>`,
    // ...
    18: `<div>... конспект билета 19 ...</div>`
};
```

Вы можете легко добавлять или редактировать конспекты, не затрагивая логику повторений.

## 📂 Контрольная работа

На вкладке **«Контрольная работа №3 | ЛДУ-II»** представлены 4 задачи:
- Метод вариации постоянных
- Метод неопределённых коэффициентов
- Две задачи Коши

Каждая задача имеет пошаговое решение, скрытое под спойлером. Решения содержат формулы в LaTeX.

## ⚙️ Технологии

- Чистый **HTML5** + **CSS3** (адаптив, неоновая стилизация)
- Нативный **JavaScript** (ES6) – без внешних зависимостей, кроме **KaTeX** для формул
- Хранение прогресса – **localStorage** + экспорт/импорт JSON
- Алгоритм интервальных повторений – собственная реализация

## 🧠 Алгоритм работы

1. Каждый билет имеет **шаг** от 0 до 5 (максимум).
2. При успешном повторении:
   - Шаг увеличивается на 1.
   - Дата следующего повторения = сегодня + `intervals[шаг-1]`, где intervals = `[1, 3, 7, 14, 30]` дней.
3. Если шаг уже 5 – следующее повторение всегда через 30 дней.
4. При откате шаг уменьшается на 1, дата повторения становится вчерашней (чтобы билет снова стал доступен сегодня).
5. История повторений хранит все даты успешных сдач билета.

## 📊 Статистика и темп

- **Количество билетов к повторению** – сколько билетов имеют `nextReview` <= сегодня.
- **До экзамена** – точное количество дней (с тремя знаками) до указанной даты (по умолчанию 11 июня 2026).
- **Темп** – показывает `✅ освоено 🔄 в процессе ⏳ не начато` и среднее количество дней на один новый билет (если не начатые билеты ещё есть).

## ✏️ Настройка даты экзамена

В файле `script.js` найдите функцию `updatePace()` и измените строку:

```javascript
const examDate = new Date(2026, 5, 11); // 11 июня 2026 (месяц 5 = июнь!)
```

Месяцы в JavaScript идут от 0 (январь) до 11 (декабрь).

## 💾 Сохранение прогресса

- **Автоматически** – при каждом действии прогресс пишется в `localStorage`.
- **Вручную** – кнопки «💾 Сохранить» (экспорт в JSON) и «📂 Загрузить» (импорт из JSON).

Файл прогресса содержит только ваши шаги, даты повторений и историю – конспекты не дублируются. Это экономит место и позволяет обновлять конспекты без потери прогресса.

## 🐛 Возможные проблемы и решения

| Проблема | Решение |
|----------|---------|
| Формулы не отображаются | Проверьте подключение к интернету – KaTeX загружается из CDN. Обновите страницу. |
| После загрузки файла пропадают конспекты | Убедитесь, что файл прогресса содержит только поля `id, name, step, nextReview, history`. Конспекты всегда берутся из `conspects.js`. |
| Не сбрасывается прогресс | Нажмите «🗑️ Сбросить прогресс» или выполните в консоли `localStorage.clear()` |
| Билеты не меняют статус | Проверьте, что у вас сегодняшняя дата – система сравнивает `nextReview` с текущей датой без времени. |
| Кнопки на телефоне съезжают | Проект адаптивен, но на очень узких экранах (<380px) кнопки могут переноситься – это нормально. |
