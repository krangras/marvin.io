# Marvin.io

Статическое учебное приложение для подготовки: билеты АГиТДУ, задачи, физика НТК, интегралы, интервальные повторения, локальный прогресс и синхронизация через Firebase.

## Что изменено в этой версии

Это структурный рефакторинг без изменения бизнес-логики приложения:

- стили вынесены в `assets/css/`;
- изображения и логотип вынесены в `assets/img/`;
- основной код приложения вынесен в `src/app/`;
- Firebase-код вынесен в `src/auth/`;
- большие файлы с учебными данными вынесены в `src/data/`;
- справочные материалы и технические заметки вынесены в `docs/`;
- из релизной папки убраны `__pycache__` и вложенный архив проекта.

## Локальный запуск

### Через Python

```bash
python server.py
```

После запуска открыть:

```text
http://localhost:8000
```

### Через Docker Compose

```bash
docker compose up --build
```

По умолчанию приложение будет доступно на порту `10101`, если не менять `docker-compose.yml`.
